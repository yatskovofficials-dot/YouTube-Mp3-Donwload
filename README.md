# YouTube Downloader Pro — Telegram Bot

Профессиональный бот: отправь ссылку → выбери формат кнопкой → получи файл.

## Форматы

### Аудио
| Кнопка | Описание |
|--------|----------|
| **MP3 320 kbps ★** | Максимальное качество звука |
| MP3 192 kbps | Хорошее качество, меньше размер |
| MP3 128 kbps | Компактный файл |
| Лучшее аудио | Без перекодирования (m4a/opus) |

### Видео
| Кнопка | Описание |
|--------|----------|
| **MP4 1080p** | Full HD |
| **MP4 720p** | HD |
| MP4 480p | Среднее качество |
| MP4 360p | Лёгкий файл |

---

## Как работает

1. Пользователь отправляет ссылку на YouTube
2. Бот показывает превью + кнопки
3. Человек нажимает нужный формат
4. Получает готовый файл (MP3 или MP4)

---

## Установка

```bash
git clone <твой-репозиторий>
cd yt-mp3-bot

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

sudo apt install ffmpeg -y   # обязательно

cp .env.example .env
# Вставь BOT_TOKEN=...

python bot.py
```
